How it works Notes MCP GitHub

Ask Claude what was said, and it looks in your own meetings.

Oorapp comes with an MCP server. Connect it once and Claude, or any other assistant that speaks MCP, can search your meetings, notes and transcribed files and read them back to you. The server is part of the app and runs on your Mac. It is free.

Connect it in one click.

In Oorapp, choose Use with Claude… at the bottom of the sidebar, then Connect Claude Code or Connect Claude Desktop. Restart Claude Desktop afterwards. Prefer to do it by hand? Pick your assistant below.

Claude Code

claude mcp add --scope user oorapp -- /Applications/Oorapp.app/Contents/MacOS/oorapp-app mcp

Claude Desktop

Open Settings, Developer, Edit Config, and add Oorapp to claude_desktop_config.json:

{
  "mcpServers": {
    "oorapp": {
      "command": "/Applications/Oorapp.app/Contents/MacOS/oorapp-app",
      "args": ["mcp"]
    }
  }
}

Cursor, Codex and other clients

Add a stdio server with the command /Applications/Oorapp.app/Contents/MacOS/oorapp-app and the argument mcp. There is no URL and no key: the server reads the meetings on your own disk.

What your assistant can do.

list_meetingsYour meetings, notes and transcribed files, newest first, with date, length and speakers. Filter by kind or by date.
searchFinds a word or a name in titles and transcripts, with the passage around each hit.
get_transcriptThe whole transcript of one meeting, with speakers and chapters, or the text of a note.
get_latestThe meeting or note you made last, transcript included.
transcribe_fileTranscribes an audio file on your Mac, with the voices told apart, and keeps it in your history. A long file takes a few minutes.

Things to ask.

  • What did we agree with Northwind this week?
  • Summarise my last meeting in five bullet points and list who promised what.
  • Find every note where I mentioned the pricing page.
  • Turn this morning's call into a follow-up mail in my own words.
  • Transcribe ~/Downloads/interview.m4a and give me the three strongest quotes.

Where your meetings go.

The MCP server only reads the folder ~/Documents/Meetings on your own computer and refuses anything outside it. Nothing is uploaded by Oorapp. When you ask Claude a question, the passages it reads become part of that conversation with Claude, like anything else you paste into it.
